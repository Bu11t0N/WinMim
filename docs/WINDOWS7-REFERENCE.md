# Эталон Windows 7

Пользователь предоставил дополнительную ВМ для сравнения оформления. Обнаружена 22.10.2026:

- VMware display name: `Windows 7`.
- VMX: `D:\Virtual Machines\Windows 7\Windows 7.vmx`.
- Конфигурация гостя: `windows7-64`.
- На момент проверки ВМ запущена, VMware Tools: `running`.

Это эталонная система, не целевая ВМ установки AeroForge. Её тему, реестр, программы и диски не изменяли. Данные учётной записи не предоставлены; учётные данные AEROFORGE-LAB здесь не применяются.

## Предоставленные изображения

Пользователь передал три снимка оригинальной Windows 7 при 1024×768: [рабочий стол](images/reference-win7-desktop.png), [меню «Пуск»](images/reference-win7-start.png), [Библиотеки](images/reference-win7-explorer.png). Они используются как визуальный эталон; ресурсы из снимков не извлекаются в оформление.

По снимкам скорректированы ширина «Пуска», минимальная высота списка и затемнение стекла правой колонки. Добавлены ярлыки доступных в Windows 10 системных программ. Состав программ отличается от Windows 7: игр и Media Center в LTSC по умолчанию нет.

Остаются различия значков и команд Проводника, оформления трея, точного размытия стекла, размеров кнопок заголовка и навигационных элементов. Для точного сравнения нужны одинаковые DPI, размер окна и содержимое папки; процент похожести не заявляется. Автоматический доступ к эталонной ВМ ограничен отсутствием гостевых учётных данных, но полученные снимки позволяют продолжать визуальную работу.
