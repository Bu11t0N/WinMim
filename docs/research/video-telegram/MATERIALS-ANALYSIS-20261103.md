## Seven: готовые материалы Open-Shell

**Главная поправка к первому отчету:** хотя ручная демонстрация идет через StartAllBack, сам PACK содержит `2. StartAllBack/Alt`: OpenShellSetup_4_4_195.exe, WIN7LIKE COMBO revE.skin7, Win7 taskbars.zip и WIN7 start buttons Unpremultiplied.zip. Значит, архив непосредственно полезен текущему пути Seven. Файл Note.txt описывает альтернативу Open-Shell и предупреждает о пересечении StartAllBack с настройками Start/taskbar ExplorerPatcher; прочие настройки EP остаются.

Скин и ZIP текстур в Telegram **побайтово совпали** с двумя вложениями автора в [ветке Classic Shell](https://www.classicshell.net/forum/viewtopic.php?t=5824). Это связывает пакет с первоисточником juniper7, но не устанавливает общую лицензию на Microsoft-графику. Кнопки отдельным upstream-скачиванием не сверялись.

Из ресурса `SKIN/1` скина статически прочитаны:

- About: WIN7LIKE COMBO revE, juniper7 2021, CSM 4.3.0; версия языка скина 3.
- Основное меню, вторая колонка и submenu используют `fullglass`.
- Есть взаимоисключающие уровни интенсивности стекла, включая LOW и LOW_MILD. Для LOW авторские настройки: **GlassOpacity меню 25, TaskbarOpacity 33**, автоматический акцент Windows 10. LOW_MILD добавляет более мягкий градиент.
- HIGH использует другой сценарий с принудительным согласованным цветом. Не смешивать HIGH/LOW и прежние фиксированные цвета случайным образом.
- Есть отдельная настройка MED_SIZE для 125% / 120 DPI; это не доказательство работоспособности всех комбинаций DPI.

В текущей исследовательской базе `DesktopProfile.BuildSeven` использует Windows Aero, фиксированный GlassColor COLORREF `0x93652F` (RGB #2F6593), TaskbarColor `0x996F46` (RGB #466F99), меню 25 / панель 38 и собственную PNG 16×40. Эти два разных цвета уже объясняют возможное рассогласование оттенков, но причинность нужно проверить на стенде. Новый согласованный скин LOW + автоматический акцент — конкретный кандидат A/B, не повод просто поменять 38 на 33 при остальных старых параметрах.

`Taskbar readme.txt` из ZIP дает настройки геометрии: вертикальное растяжение, **TaskbarBordersV 2,0**; для dark ends горизонтальное растяжение, **138,219**, рисунок рассчитан на экран 1920. При 0,0 края растягиваются. У нынешней генерируемой WinMim PNG используются горизонтальный Tile и вертикальные границы 1,0 — это другой ресурс и другие настройки. Варианты ZIP нельзя подменять без согласования режима растяжения.

Затем отдельно проверять dark ends, нижнюю/верхнюю/вертикальную панель и второй монитор. На Win10 автор упоминает запаздывающее обновление фона панели; его обходы не применялись на компьютере пользователя.

### Полезная конфигурация Explorer

Иконки ссылаются на `%SystemDrive%\Classic\win98buttons`; Back/Папки имеют русские подписи. Для ряда команд есть disabled-ресурсы, но CutItem.IconDisabled совпадает с обычным. ### Встроенный текст AHK восстановлен без исполнения

В архиве нет отдельных `.ahk`, но в RCDATA `>AUTOHOTKEY SCRIPT<` обоих EXE сохранился текст. Он извлечен в приватные `bar.ahk.txt` и `classic.ahk.txt`; PE-манифест содержит путь ресурса, размер и SHA.

`bar`: shell-hook при создании окна; NotebookFrame/NotebookContent1, Notepad/Edit1 и ConsoleWindowClass получают ExStyle `0x200` с изменением высоты на один пиксель и обратно для перерисовки. Для CabinetWClass сообщения `0x108F` / `0x108E` читают/меняют extended style SysListView321 при конкретном возвращаемом значении. Для создаваемых окон передается атрибут композиции 19 с первым полем политики 1.

`classic`: подписывается на события 1/6/4, но блок изменений внутри дополнительно ограничен событием создания 1; задает ту же композиционную политику и рамки для Notepad/Console. Это не цикл принудительного обновления всех окон при каждом фокусе. Не считать скрипты реализацией Common Tasks, восстановлением системных диалогов или кодом AHK v2. Исходное состояние стилей не журналируется; выключение процесса само по себе не доказывает полный откат уже измененных окон. Для WinMim полезны конкретные случаи перерисовки/вложенных контролов, а не запуск двух готовых EXE.

### Чего не переносить из рецепта запуска

В `2. Task Scheduler/Fourth/REGEDIT.txt` Userinit под Winlogon заменяется командой schtasks для задачи Classic. Скриншоты описывают цепь Classic → Apps/ApplicationFrameHost, ClassicThemeTray /enable, Classic2 → userinit.exe, refresh.bat. BAT принудительно завершает explorer.exe и StartMenu.exe по имени и запускает их по жестко заданным путям. Это не пригодная архитектура запуска/возврата WinMim.

`3d_borders.reg` перезаписывает целый восьмибайтовый UserPreferencesMask значением `9E 1E 05 80 12 01 00 00`; для целевого эффекта нужно выделить и проверить нужные биты, сохраняя остальное. Цветовые схемы находятся в HKCU Control Panel Appearance Schemes; это классические палитры, не Luna msstyles. Старый EP REG использует ветку под Explorer\ExplorerPatcher, содержит удаления CLSID и HKLM-записи; не сливать с текущим конфигом. Defender-control, branding DLL и CPL из чужой версии Windows не переносить.

## Рекомендации координатору и критерии готовности

1. **P0 Seven, tint/панель:** оригинальные скин/текстуры и LOW 25/33 — проверить в отдельном приватном стенде через существующий DesktopProfile, сохраняя исходные значения Open-Shell. Сначала согласовать скин, акцент и альфу; OpenGlass не менять. Успех — одинаковый оттенок меню/панели, корректные края и обновление фона, работа на 100/125%, после Explorer restart и полный возврат.
2. **P0 XP:** дождаться штатной загрузки Luna10, вычислить хеш, прочитать руководство, установить точные компоненты Common Tasks и BasicThemer, передать XP-исполнителю. Текущие сведения страницы не объявлять содержимым ZIP или доказанной совместимостью.
3. **P1 2000 Explorer:** использовать XML как перечень реальных команд, локализованных подписей и отдельных изображений; не переносить старую DLL. Проверять Back/Forward/Up/Cut/Paste/Delete и все виды на RU/x64, а не только рисунок toolbar.
4. **P1 2000 controls:** изучить конкретные вложенные Edit/Console/Notebook случаи из AHK; собственная обвязка должна владеть только своими окнами/изменениями, хранить исходные стили и учитывать закрытие/повторное создание HWND.
5. **P2 ресурсы:** отделить пиксели/иконки/звуки от кода, подтвердить лицензии каждого набора. GPL Open-Shell не лицензирует автоматически вложенные Microsoft-рисунки.
6. **Не интегрировать пакетом:** Userinit/scheduler, DLL replacements, 7tsp, EP/StartAllBack и DWM helpers требуют отдельных решений и проверяемого rollback. Нет оснований понижать версии существующих зависимостей.
