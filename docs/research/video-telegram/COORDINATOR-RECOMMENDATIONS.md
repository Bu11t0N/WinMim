# WinMim: рекомендации координатору, 3 ноября 2026

Код продукта и ВМ не менялись. Все новые выводы — статический анализ оригинальных архивов, без их установки. Полное описание и хеши: [разбор материалов](MATERIALS-ANALYSIS-20261103.md). Прежние видеотаймкоды: [исторический отчет](VIDEO-TELEGRAM-FINDINGS.md).

1. **P0 XP — Luna10.** [Страница vaporvance](https://www.deviantart.com/vaporvance/art/Luna10-907548273) заявляет 2.1.5, Windows10 1903–22H2, BasicThemer2/6, Open-Shell и динамическую Common Tasks pane, только 96DPI/100%. Требуется штатный вход для ZIP; пользователь согласился войти и сообщить. Пока ZIP не получен, состав/хеш неизвестны. После загрузки прочитать руководство и проверить реализацию панели. Не путать с FindeXer/Freestyle SP1 и не мешать Luna с classic-frames. Для публичной поставки отдельно разрешить условия ресурсов; автору не писали.

2. **P0 Seven — готовый Open-Shell путь найден в [PACK, пост2243](https://t.me/daneo03/2243).** Каталог Alt содержит Open-Shell4.4.195, WIN7LIKE COMBO revE, текстуры и кнопки. Скин/ZIP текстур побайтово совпадают с [первоисточником juniper7](https://www.classicshell.net/forum/viewtopic.php?t=5824). Рецепт LOW: меню25/панель33, автоакцент. Сравнить с нынешними разными фиксированными COLORREF, не переносить только одно число. Текстуры opacity33/85 имеют разную собственную альфу; vertical borders2,0, dark-ends horizontal138,219 вместо текущего Tile/1,0. Точка изменения для отдельной разработки — DesktopProfile.BuildSeven и его журналируемые Open-Shell settings. Проверки: один фон/цвет/DPI, текущая PNG → без PNG → оригинал; края, ориентации, второй монитор, Explorer restart, rollback. OpenGlass оставлять отдельным владельцем DWM.

3. **P1 Windows2000 — [W2KTheme, пост1432](https://t.me/daneo03/1432) получен.** Полезны Explorer Settings.xml, настоящие toolbar-команды, localized labels и win98buttons. Воссоздавать через свой адаптер/закрепленный Open-Shell, проверяя реальные Back/Forward/Up/Cut/Paste/Delete/виды. Отдельная StartMenuDLL.dll имеет версию4.4.1000 при установщике4.4.160: происхождение модификации не установлено, замену исключить. RetroBar1.9.46 старее уже закрепленного1.22.122.

4. **P1 controls2000 — текст AHK извлечен из EXE.** bar/classic — AHKv1 разных версий; shell-hook, composition policy и рамки дочерних контролов Notepad/Console/Notebook. Это конкретные примеры для собственной узкой обратимой реализации, без запуска готовых EXE. Исходные стили не журналируются; завершение процесса не является доказанным rollback.

5. **P2 DWM/ресурсы.** В Seven DWMBlurGlass EXE2.3.0.0/Ext2.2.0.0 и исходный AeroConfig.ini. Числовые настройки не переносить в OpenGlass; второй DWM engine не включать. Scheduled restart по событию9027 — обход падения, не исправление причины. Скин, кнопки, иконки, branding и звуки имеют отдельные условия; публичная доступность не дает права включения в открытые сборки.

Не переносить цепь Winlogon/Userinit, принудительное убийство процессов по имени, полный UserPreferencesMask, Defender-control, системные DLL от build22000, старые REG/EP и весь 7tsp-пакет. Для этих действий нет ни необходимости, ни подтвержденного точного возврата. Совместимость найденных пакетов с 19044 не проверена запуском.
