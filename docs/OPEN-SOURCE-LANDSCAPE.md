# Open-source projects relevant to WinMim

Reviewed on 2026-10-29 using upstream repositories, READMEs and license files. Proposed uses are engineering assessments, not completed integrations or compatibility guarantees. Research does not change WinMim's pinned dependency versions.

| Project and primary sources | Upstream license | Useful work for WinMim | Decision / limits |

Replaces the taskbar, not Explorer contents or global window controls. Start-menu routing and balloon notifications need explicit lab tests. Upstream's feature list is not a WinMim test result. |

## Proposed integration order

1. Stabilize VM boot and controller versioning. Adding another shell backend cannot substitute for this.
2. Prototype **RetroBar + Open-Shell** on a cloned disposable VM. Test taskbar properties, Start routing, auto-hide, tray overflow, notifications, keyboard layout, DPI, multiple monitors, Explorer restart and restore.
3. Keep **visual styles + OpenGlass + selected Windhawk modules** for Windows 7. Use the gap list to choose each change.
4. Define a component contract: detection, supported builds, pinned source/package, configuration plan, apply, health check, shutdown and restore. Select one taskbar owner per profile.
5. Build per-appearance resource manifests recording source, license, author, revision and SHA-256. Installer code licenses do not automatically cover Windows artwork or extracted binaries.

No new project listed here was installed automatically as part of this research. The next code step should be the smallest measurable integration that closes a known gap.
