# Исследование Revert8Plus: источник и сравнение состояний

## Зафиксированный экземпляр

Файл пользователя `r8p.exe`, 120105882 байта, build **1137**.
SHA-256: `c13aa6cca4e5eac69095a55e2cdc0daf6e4185bc4d169974c30d3d7a90bd1464`.
В PE-ресурсах обнаружен читаемый AutoHotkey-сценарий; во встроенном архиве — 54 файла исходников модулей и 10 файлов `.reg`. Это сведения статического анализа, не результат успешной установки.

Инвентарь: [r8p-static-inventory.json](evidence/r8p-static-inventory.json). Создан нашим `tools/inspect_r8p.py` из уже извлечённых данных без исполнения установщика. Сценарий и бинарные ресурсы r8p в дистрибутив AeroForge не добавлены.

## Найденные механизмы

| Область | Действия установщика build 1137 | Значение для AeroForge |
|---|---|---|
| Движок | Служба `Windhawk`, автоматический запуск, команда `%WINDIR%\Revert8Plus\Windhawk.exe -service` | Отличается от пользовательского portable host; нужны отдельные испытания жизненного цикла и прав |
| Модули | Собственные адаптеры тем, DWM, ресурсов, реестра и запуска компонентов | Изменение одного реестра не заменит перехваты внутри процессов |
| Темы | SecureUxTheme, IFEO `winlogon.exe`, копирование `.theme`, ThemeSwitcher | Изучить взаимодействие с сервисом тем и входом; не переносить IFEO автоматически |
| DWM | Настройки из `dwm.reg`; отдельный модуль проверяет тип темы и перезапускает DWM | Возможное объяснение отличий после смены темы; требуется собственный проверенный протокол |
| Ресурсы | Файлы перенаправления ресурсов/реестра и варианты Seven/Vista | Создать сопоставление по функциям и собственные ресурсы |
| Дополнения | Условная замена UAC/VAN/ExplorerFrame/Help, отдельные пакеты Media Center/игр/гаджетов | Проверять раздельно; состав определяется выбранными опциями |
| Символы | Загрузка PDB с Microsoft до запуска службы | В клоне без сети нужно подготовить точный кеш заранее |
| Права | Разрешения для ModsWritable, Symbols и некоторых ключей; исключения Defender | Зафиксировать как наблюдаемые действия; не включать в AeroForge механическим импортом |

Инвентарь содержит также действия удаления прежних установок. Строки скрипта показывают возможные операции, а не число реально выполненных изменений. Профильные `.reg` могут перекрывать друг друга; импорт всех найденных значений в наш профиль не допускается.

В заголовках 54 извлечённых модулей не обнаружено явного `@license`. Наличие исходников внутри установщика само по себе не задаёт разрешение на перенос. Для каждого используемого компонента нужны его исходный upstream и применимые условия. Собственная реализация AeroForge и зависимости с уже проверенными лицензиями остаются отдельными.

## Изолированный стенд

Текущая ВМ AeroForge не используется как исходное состояние сравнения. Эталонная Windows 7 не изменяется. Клон первоначально не имел сети. 23 октября после исходного замера добавлен адаптер e1000 с VMware NAT для загрузок установщика; исходный VMX сохранён. Общих папок нет. Сетевые изменения требуется отделить контрольным замером до установки.

Исходный [рабочий стол клона](images/r8p-reference-before.png) подтверждает чистое оформление Windows 10. Для снижения нагрузки исходная ВМ AeroForge приостановлена с сохранением состояния; работает исследовательский клон.

На хосте используется `work/vm/guest_r8p.py`, ограниченный точным VMX этого клона; учётные данные не включены в проект. Маркер `C:\R8P-Lab\reference.marker` обязателен для сборщика. В госте исходный установщик находится в `C:\R8P-Lab\r8p.exe`.

## Воспроизводимый эксперимент

1. Снять `before` через 64-битный Windows PowerShell 5.1 (Desktop) обычного интерактивного пользователя (здесь используется отдельная задача `AeroForge-R8P-Capture-Before`, чтобы VMware запускал сборщик в правильном сеансе): `Capture-R8PReference.ps1 -Phase before`. Проверить `complete.json` и `issues.json`; не запускать установку при незавершённом сборе.
2. Снять `control` после такого же периода ожидания без установки: так видно фоновую активность Windows. Сохранить снимок ВМ перед r8p.
3. Для build 1137 записать выбор Standard или Full. В исходном сценарии Custom отображается, но обработчик запуска отсутствует. Standard автоматически скачивает Media Center/DVD Player, гаджеты и игры; Full добавляет Help, UAC, VAN и ExplorerFrame. Для исходного установщика необходим доступ к его URL и Microsoft Symbols. Принудительный обход HTTPS-проверок не применяется.
4. После завершения снять `after-install`, затем после согласованного перезапуска — `after-reboot`. Фиксировать скриншоты и проверять фактическую загрузку модулей отдельно.
5. Передать каталоги capture на хост и выполнить `python tools/compare_reference.py BEFORE AFTER --output REPORT.json`. Не публиковать сырые дампы реестра без проверки содержимого.

Сборщик сохраняет заданные ветви реестра, SHA-256/длины/SDDL файлов в записанных областях, службы, задачи и ссылки. Он не обходит directory reparse points, не меняет настройки ОС и не собирает SAM/SECURITY, пароли или пользовательские документы. Ошибки доступа сохраняются в coverage; неуспешный экспорт не трактуется как отсутствие ключа. Сравнение не генерирует сценарий импорта.

Не охвачены все файлы Windows, полный ACL реестра, загруженные перехваты и каждый переход состояния процессов. Изменение файла либо ключа не доказывает его влияние на оформление: каждый переносимый эффект надо воспроизвести отдельно нашим движком и проверить возврат.

## Состояние работы

Статический инвентарь и инструменты capture/diff готовы. Четыре автоматические проверки сравнения охватывают типы и продолжения `.reg`, шум временных меток, ACL, неполные снимки и различие отсутствия ключа/ошибки экспорта. Установка r8p и динамическое сравнение ещё не завершены. Computer Use не смог захватить окно VMware: `FrameArrived timed out`, затем `window capture timed out`; после восстановления сессии повторный захват также не удался. VMware API остаётся доступным для файлов и запуска сборщика.

Снимок клона: `Before-R8P-Build1137-20261023`. Проверка зависимостей с хоста: все четыре URL отвечают HTTP 200. В клоне DNS работает; базовый GitHub отвечает HTTPS 200 как с настройками WinHTTP по умолчанию, так и с TLS 1.2. Соединение с URL пакета проверяется отдельно. Установка r8p ещё не подтверждена.

## Результат Full: сетевой таймаут и откат

Установка Full build 1137 дошла до подготовки символов и завершилась исключением WinHttp.WinHttpRequest 0x80072EE2 (Send), строка 1235. [Снимок сообщения](images/r8p-full-timeout.png). Эта строка в извлечённом AHK выполняет HEAD конкретного PDB на Microsoft Symbols. Точный PDB, на котором случился таймаут, из окна ошибки определить нельзя. Выполнен собственный откат r8p, итоговый мастер сообщает неуспех. Успешная установка и оформление не заявляются.

После ошибки отдельный запрос известного URL explorer.pdb из того же клона дважды дал HTTP 200 (около 2,1 и 0,6 секунды). [Показания](evidence/r8p-symbols-network.json) подтверждают доступность этого URL в момент проверки, но не доказывают исправность всех PDB. [Чтение темы после отката](evidence/r8p-desktop-after-failure.json) показывает исходные Aero.msstyles и img0.jpg. Идёт замер after-install; в этом опыте имя фазы означает состояние после неудачной попытки и отката, а не успешную установку.

В собственном лабораторном загрузчике символов добавлены три попытки для временных ошибок сети/HTTP. 404 сразу передаётся существующей логике альтернативного имени PDB, проверки идентичности GUID/возраста сохранены, сертификаты проверяются штатно. Ограничение размера теперь обнаруживает слишком большой ответ явно. Это изменение нашего инструмента; оригинальный r8p не патчился.


Предварительное сравнение готового экспорта реестра с control: 360 уникальных различий, 0 недоступных областей. Это включает фоновую активность Windows и не означает 360 настроек r8p. После отката отсутствуют обе исходные ветви HKCU/HKLM Software\Microsoft\Windows\DWM; сценарий удаления оригинала явно выполняет RegDelete этих ветвей (строки 748–749). [Сводка без сырых значений](evidence/r8p-rollback-registry-summary.json). Возврат оформления не равен точному возврату всех исходных параметров. В AeroForge применяются и возвращаются отдельные значения по журналу, без удаления всей ветви DWM.
