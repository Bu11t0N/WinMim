# Соответствие функциям Revert8Plus

**Актуальная проверенная точка:** [полные значки, классический Проводник и нативные компоненты, 24.10](SEVEN-PROGRESS-20261024.md). Описания ниже, противоречащие этому обновлению, относятся к более ранним сборкам.

Обновление 24.10.2026: новые модули поведения, настройки панели и системный адаптер описаны в [SEVEN-BEHAVIOR-20261024.md](SEVEN-BEHAVIOR-20261024.md). Историческая таблица ниже сохраняет задачи для полного соответствия.

Проверено 21.10.2026. «Собрано» означает наличие скомпилированного модуля, а не испытания в Windows. **Полное соответствие пока не достигнуто.**

| Функция | Что есть в AeroForge 0.1 | Что осталось |
|---|---|---|
| Установка, изменение, удаление | План, изолированный host, журнал, конфликтный откат, тесты | Испытания после живого запуска host и перезагрузки |
| Меню «Пуск» Windows 7 | Проверяемая загрузка Open-Shell | Автоматический профиль настроек и скин с открытой лицензией |
| Панель задач | Модули Aero Peek; отдельный набор исправлений трея | Полный профиль размеров, кнопок, группировки и стекла |
| Проводник | Aerexplorer, treeview, statusbar и старые команды собраны | Проверка с конкретными DLL/UBR и доводка настроек |
| Aero Glass | Проверяемый официальный установщик OpenGlass | Управляемый адаптер, версия под ОС, восстановление его настроек |
| Стандартные контролы и msstyles | SecureUxTheme доступен отдельно | Собственные воспроизводимые стили Seven/Vista и их лицензированный исходный материал |
| Basic | Basic Themer собран | Испытание DWM и безопасная интеграция; обычный план блокирует |
| Classic | Classic Theme собран | Испытание системного процесса; обычный план блокирует |
| Трей, часы, всплывающие окна | Соответствующие модули собраны | Интерактивная проверка и точное оформление |
| Alt+Tab | Собственная оригинальная реализация, включаемая отдельно | Проверка клавиатуры, окон разных типов, мониторов и DPI |
| Панель управления | Control Panel Revival собран | Проверка страниц; отсутствующие Microsoft апплеты не поставляются |
| Заголовки UWP | Classic UWP Fix собран | Полная поддержка удаления/перерисовки заголовков |
| Экран входа | Нет реализации | Отдельный проект и испытания logon без замены системных DLL |
| Контекстные меню | Eradicate Immersive Menus и Classic Menus собраны | Проверка конфликтов и приложений |
| Копирование файлов | Legacy File Copy собран | Проверка Explorer, диалогов и прогресса |
| MessageBox | Message Box Fix собран | Проверка тем, DPI и приложений |
| Aero Peek | Модуль Show Desktop собран | Проверка мониторов и поведения |
| UAC | Модуль затемнения собран | Проверка secure desktop; обычный план блокирует |
| Иконки | Resource Redirect собран | Открытый пакет ресурсов; до него модуль блокируется |
| Звуки и обои | Готового пакета нет | Создать собственные или подключить лицензированные |
| Windows Media Center | Собственный локальный медиаплеер | Медиатека, навигация с пульта, ТВ/запись не реализованы |
| DVD | Используются доступные кодеки Windows | Отдельный открытый backend и правомерная поддержка форматов |
| Гаджеты | Собственные часы, память и заметки | Плагины и совместимость с другими гаджетами |
| Игры | Собственный Сапёр | Пасьянсы, Mahjong и остальные игры |
| Настройки | Выбор модулей, редактирование значений, импорт/экспорт | Типизированные редакторы, пресеты, постоянная библиотека профилей |
| Поддержка Windows | Проверка базовой Windows 10 x64 | Матрица UBR, Windows 11, ARM64, автоматические VM-испытания |

Полный аналог требует закрыть все оставшиеся пункты. Наличие строки в этой таблице не объявляет функцию реализованной.

Внешняя тема не включена в открытый дистрибутив.
